# 路线图与验证记录

## 0.1目标

完成本地AI接题入口、材料索引、阶段规划、可复现实验、底表、离线图表审阅、MD/HTML/PDF、实际ZIP核验与冻结。用优化与预测两类合成示例验收，不改动原竞赛项目。

## 本轮状态

2026-09-27，0.1版本地实现及验收完成，具备独立源码、中文AI入口、安装包、合成示例与回归测试。没有创建远端仓库、发布包索引或自动上传任何比赛平台；原比赛工程与冻结成品不改动。

开发虚拟环境复用了本机现有科学计算包；干净环境只验证核心安装与初始化，未伪称全套科学环境跨平台冷安装已测。Linux/macOS、其他Python版本、真实新赛题、团队理解与当届比赛合规尚未验收。

示例保存在本地被忽略的`workspaces/demo-assignment`和`workspaces/demo-forecast`。正式候选以各自`deliverables/candidate.json`为入口，早期候选只作历史。图表选择是自动验收操作，不代表用户的人工选稿。冻结阻断已在临时测试工作区验证，演示目录保持可编辑，方便继续试用。

本轮工程、示例和文档由Codex辅助实现；没有把自动检查记为团队审定。开发中保留并修复了三个重要问题：手改底表不能仅靠重填哈希变有效；重签ZIP清单仍须逐项对应源码；旧HTML和构建日志不能混入当前PDF交付包。

## 已知范围

- 由当前AI会话做赛题推理和程序实现；不含后台LLM服务或无人值守付费执行。
- 图表模板仅覆盖标量指标比较；PDF文本提取不保留所有公式，扫描页和图像须另行渲染检查。
- 预测示例只证明时序留出流程，不是滚动验证或现实泛化证据。
- 命令运行器不是安全隔离。总预算与比赛合规仍需AI和用户明确管理。
- 自动数值替换只覆盖登记表达式；数学推导、任意手写数字、全部匿名性和人工理解不能自动证明。
