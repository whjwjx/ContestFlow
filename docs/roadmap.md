# 路线图与验证记录

## 2026-09-29 Alpha 发布收尾（0.2.0a1）

当前定位为“团队主导、面向 Agent 的数模竞赛工作流与可复现工具包”。在原有协作流程、资源复用和赛前预检之上，补齐薄 skill 与此前已复现的发布阻塞。以下状态更新替代下方历史记录中的“仍待修复”；历史测试和示例数字保留当时语境。

- 新增自包含的 `skills/contestflow/`：38 行主入口、三份阶段指南及可选界面元数据。入口负责范围和协作，既有 CLI 继续负责实际执行。skill 不安装依赖，不启动后台模型，也不把收到题面当成一路提交的许可。
- 论文移除自动嵌入外部资源，采用受限 Markdown/Bib 与 `paper/figures/` 内 PNG/JPEG；解析与引用处理后分别检查 AST，拒绝原始 HTML/TeX、元数据、自定义 CSS/宏和外部图片。草稿、配置、Bib、图片的实际使用字节绑定快照，资源策略实现进入构建身份。
- 烟测在启动前检查命令、结果路径、有限超时（0 到 180 秒）、指标与容差；超时、等待异常、结果异常和中断均进入进程树清理。不会将旧结果当成本次复现。
- 分配例改为固定整数递推与 seed 生成，基线 66、独立枚举及 SciPy 最优 44；记录配方与数据哈希，不再使用未经核实的自创或公有领域描述。旧工作区不重写。
- 提高已核对的依赖下限，新增审计 extra、Windows/Python 3.13 依赖快照、实际 wheel/sdist 内容检查和跨平台 CI 配置。更新安全报告方式与发布清单，没有将未验证的远端设置写成已启用。

## 2026-09-29 资源复用与赛前预检

本轮把“跨比赛复用”落为资源定义、本次选择、本机工具配置和预检记录。仍由团队选择研究路线与最终呈现；自动盘点、合成演练和选色均不表示人工审定或可提交。原比赛项目、真实数据和冻结成品未迁移。

- 新增资源库：6 个工具条目和 5 套配色，保存来源、用途、依赖、固定检查组、复用说明与积累状态；支持共享自定义 JSON。历史 P6/P7 仅为项目使用过的三色子集，不标成完整官方调色板或已通过可访问性验证。
- 图表按所选配色生成，未选时保持原三套；资源定义或字体配置改变会使旧审阅过期，已有选择不被资源命令覆盖。
- 新增 tools 本机配置与统一发现：明确路径、环境变量、当前 Python 环境、PATH、包内 Pandoc、Windows App Paths 与有限补充目录。配置失效明确报错；补充搜索多候选需明确选择，避免静默换版本。doctor 与论文构建共用解析器。
- 新增 preflight 的 inventory / functional / rehearsal 三层：包与工具盘点、固定小样例、独立合成预测流程。所选资源自动加入所需检查；GPU 按需，报告区分通过、失败、缺失、未验证和不需要。
- 中文字体解析与实际论文构建统一；MiKTeX 预检和演练禁止自动补包。子进程受组级超时约束；本机配置和 .contestflow 报告目录被忽略并拒绝进入交付包。Windows 管道中的 CLI JSON 统一 UTF-8。
- 本轮代码与文档由 Codex 辅助实现并经独立代码审查；未把这些检查记成用户看稿、模型理解或比赛合规审核。

## 已知范围

- 团队作出建模与提交判断，当前 AI 会话按授权辅助推理和实现；不含后台 LLM 服务或无人值守付费执行。

- 预测示例只证明时序留出流程，不是滚动验证或现实泛化证据。
- 命令运行器不是安全隔离。总预算与比赛合规仍需AI和用户明确管理。
- 自动数值替换只覆盖登记表达式；数学推导、任意手写数字、全部匿名性和人工理解不能自动证明。
