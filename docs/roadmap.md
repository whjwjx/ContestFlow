# 路线图与验证记录

## 0.1目标

支持团队主导的全流程 AI 辅助：材料索引、阶段协作、可复现实验、底表、图表审阅、MD/HTML/PDF、实际 ZIP 核验与冻结。用优化与预测两类合成示例验收，不改动原竞赛项目。

## 2026-09-29 团队主导的协作入口

当前定位为“团队主导的数模比赛全流程 AI 辅助工作台”。此前首屏和默认提示强调交题后持续自主推进，容易让读者把预设工具链成功理解为比赛研究已经完成。本轮把团队在题意、模型、预算、证据解释、论文和提交上的判断落实到默认入口与阶段提示，保留 AI 在已授权范围内连续完成工作，不增加逐条命令审批。

- 首页、源码仓库 AGENTS、工作区模板和适配文档改为按阶段协作；默认先整理读题包，实际团队意见与 AI 建议分开记录，真实 AI 贡献仍须披露。
- next/plan 兼容追加 collaboration_mode、guidance_only、team_focus、human_review；已有 stage/action/automatic 键保留，schema_version 仍为 1。阶段来源仍是产物状态，不是批准状态；status 不推断人工审定。
- 新工作区的 DECISIONS 模板提示记录目标、AI 产物、自动检查、实际团队决定及下一步；plan 刷新不覆盖团队记录或既有 AGENTS。
- CLI 帮助、demo 输出和示例论文首屏区分预设教学演示、候选产物与真实比赛。未替已有工作区改写规则或成品，也未重建原 dist。
- 本轮代码和保留文案由 Codex 辅助实现与审查，人工试用与团队审定尚未完成。

实际验证：Windows/Python 3.13.7，53 项回归通过（16.28 秒）；包含两个教学例的 HTML 构建、实际 ZIP 烟测和冻结。Ruff 静态检查通过。新增/扩展验证覆盖 start 不生成方案、next/status 只读、技术交付和冻结不推断人工审阅、plan 保留旧团队记录。核心启动测试已移出依赖科学包的整体跳过条件。该测试环境复用现有依赖，不代表跨平台或干净科学环境验收。

范围：这次落地的是协作约定与状态表达，没有新增基于身份的人工签认或强制审核门禁。旧工作区需阅读并合并新版 AGENTS 原则，再刷新未冻结工作区的 plan；不重新初始化或覆盖旧记录。

开源审查中的文档资源越界/自动联网、烟测非法超时清理、依赖审计和示例来源问题仍待单独修复与验证；本轮定位调整没有使其自动解决。已配置 GitHub 远端，公开可见性尚未确认，本轮不推送或发布。

下一步：用一份有权使用的题面做团队分阶段试用，检查读题包能否支持选题、模型取舍能否被解释、阶段结果是否便于审阅。若仍需要逐条提示才能协作，再按真实卡点优化；发布前先完成上述安全与来源修复，不以文案替代验收。

开发虚拟环境复用了本机现有科学计算包；干净环境只验证核心安装与初始化，未伪称全套科学环境跨平台冷安装已测。Linux/macOS、其他Python版本、真实新赛题、团队理解与当届比赛合规尚未验收。

示例保存在本地被忽略的`workspaces/demo-assignment`和`workspaces/demo-forecast`。正式候选以各自`deliverables/candidate.json`为入口，早期候选只作历史。图表选择是自动验收操作，不代表用户的人工选稿。冻结阻断已在临时测试工作区验证，演示目录保持可编辑，方便继续试用。

本轮工程、示例和文档由Codex辅助实现；没有把自动检查记为团队审定。开发中保留并修复了三个重要问题：手改底表不能仅靠重填哈希变有效；重签ZIP清单仍须逐项对应源码；旧HTML和构建日志不能混入当前PDF交付包。

## 已知范围

- 团队作出建模与提交判断，当前 AI 会话按授权辅助推理和实现；不含后台 LLM 服务或无人值守付费执行。
- 图表模板仅覆盖标量指标比较；PDF文本提取不保留所有公式，扫描页和图像须另行渲染检查。
- 预测示例只证明时序留出流程，不是滚动验证或现实泛化证据。
- 命令运行器不是安全隔离。总预算与比赛合规仍需AI和用户明确管理。
- 自动数值替换只覆盖登记表达式；数学推导、任意手写数字、全部匿名性和人工理解不能自动证明。

## 后续优先级

1. 先修复已确认的开源前安全与来源问题，再以真实新赛题验证团队阶段协作和跨小问衔接。
2. 加入跨调用预算、更多输入适配、完整PDF图片索引和规则配置校验。
3. 扩展配对/分布/消融图表与可声明证据契约，不无限增加样式。
4. 按真实需求接入可选模型服务；先明确凭据、费用、任务隔离和停止条件。
5. 独立团队试用后再公开发布。未来才考虑更多比赛模板、DVC和Word主稿模式。
